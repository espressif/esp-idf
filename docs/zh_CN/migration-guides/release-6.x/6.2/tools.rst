Python 3.10 弃用说明
----------------------

Python 3.10 已不再受支持。现在要求的最低 Python 版本为 3.11。请将你的 Python 升级至 3.11 或更高版本。最简单的方式是使用较新版本的 ESP-IDF Installation Manager (EIM)，它会检查前置条件并提示安装缺失项；详见 `EIM 文档 <https://docs.espressif.com/projects/idf-im-ui/en/latest/>`_。也可以使用提供的 Docker 镜像，详见 :ref:`idf-docker-image`。

参考 `Python 官方文档 <https://docs.python.org/3/using/index.html>`_ 获取不同操作系统的 Python 升级指南。

对于 Linux 用户，建议升级到包含受支持 Python 版本的较新发行版。
